## Auditoría y corrección de la página de notas

### Hallazgos de la auditoría

| Defecto encontrado                          | Por qué era un problema                             | Cómo se corrigió          |
| Nombre de archivo con espacios y mayúsculas | Dificulta la organización y referencia del archivo. | Se cambió a `index.html`. |
| Nombre del CSS con espacios y mayúsculas    | Dificultaba la referencia y su organización.        | Se cambió a `styles.css`. |
| Variable `data1` sin uso                    | era un código innecesario.                          | Se eliminó.               |
| Variable `TempValue2`                       | No describia claramente la información almacenada.  | Se cambió a `promedio`.   |
| Variable `x`                                | No indica apropiadamente qué representa.            | Se cambió a `cantidadNotas`.|
| Variables `a`, `b`, `c`                     | Sus nombres no describen las notas.        | Se cambiaron a `nota1`, `nota2` y `nota3`. |
| Función `calc()`                            | El nombre no describe claramente su función. | Se cambió a `calcularPromedio()`. |
| IDs `n1`, `n2`, `n3`                        | No son descriptivos.                     | Se cambiaron a `nota1`, `nota2` y `nota3`. |
| IDs `r` y `r2`                         | No indican qué resultado muestran. | Se cambiaron a `resultadoPromedio` y `resultadoEstado`. |
| Título `pagina`                             | No identifica correctamente el sitio.       | Se cambió a `Calculadora de Promedio`. |
| `console.log()` innecesarios                | Son mensajes de depuración que no necesita el usuario.  | Se eliminaron. |
| Código comentado sin uso                    | Mantiene código que ya no forma parte del funcionamiento. | Se eliminó. |
| Clase `cont1`                               | No describe el contenido del elemento.              | Se cambió a `calculadora`. |
